# 云朵花语：Product Design 复评与改版策划

日期：2026-11-16。范围：云朵花语桌面首屏、分类入口、右侧作品阅读。此次只策划，不修改运行代码。
证据：本轮 Chrome 原生截图 01-overview.png、02-project.png。对标为用户提供的90秒视频及说明；对标制作方法属于作者陈述，未检查其源代码。

## 目标与保留约束

为初次访问者提供可探索、可直接浏览作品的治愈小岛。保留用户选定的一号布局、二号建筑、一号水塔，名称云朵花语。保留人物黑夹克、牛仔裤、白鞋；动物数量由分类配置生成，建筑固定。水獭游泳、小船起伏、秋千前后摇摆。圆润、稀疏，避免密集颗粒。其他场景本轮不重制。

## 现场复评

1. 进入场景：可用，视觉需重做。粉色主屋识别明确，海面铺满画面；但主屋压过其他建筑，道路是宽色带，岛缘石头等间距如串珠。坡道仍见黑色细碎痕迹，原因需从几何/深度/阴影定位，不仅用抬高路面掩盖。
2. 点击分类入口：可用，映射需改。文字标签能打开对应作品，但后方水獭被岛遮挡时，标签浮在花房/树上，用户无法知道标签指向谁。底部固定分类是必要的稳定替代入口。
3. 阅读作品：可用，内容呈现不足。右侧面板有明确关闭按钮、分类标题、项目与公开来源；没有作品缩略图，标题末字孤行。面板覆盖右上全景/帮助控件。底部已浏览表示分类访问，不等于看完作品，应明确含义。

可访问性风险：海面上的小号灰绿文字和半透明标签可能对比不足；运动目标不易点中。此次未测量对比率、键盘焦点循环、读屏、手机与低性能设备，不声称无障碍通过。截图来自已有浏览记录，不能当作首次访问进度状态。

## 美术方向

定位为“海边花园里的个人作品集”。从对标借鉴建筑细节、层次与环境衔接，不照搬其五栋建筑、中央桥池或工作台功能。

空间：后左高台花房为主视觉，后右薄荷小屋为次视觉，中间弯曲小径连接前方低台花园；左前内凹海湾接码头，右前木廊秋千面向海。保留三块清楚可读的空间，不增加密集建筑。
比例起点：主屋视觉体量比当前缩减约15%–20%，小屋增加门廊与窗框厚度而不靠整体放大；最终以固定视角截图校准。道路局部收窄、圆角连接，岸线形成连续草沿与不规则成组岩体，不做等距装饰环。
材质：奶油墙面、柔粉屋顶、薄荷木作、暖木码头；细节放在窗框、屋檐、门阶和少量花箱。树冠采用融合团块与少量叶簇，花卉以疏朗簇群组织。海面减少平行条纹，增加低频颜色变化、浅水岸带、低对比岸波。暖主光与柔和接触阴影保持物体落地。

## 资产路线

继续用Three.js承担浏览器渲染、相机、交互和动态。花房、小屋、水塔、水獭作为独立可替换资产；地形、道路、海水与轨迹由代码控制。
先完成“花房＋一小段地面＋一只水獭”的真实浏览器质量样板。分别检查正面、侧面、近景与默认远景，再扩展整岛，避免整张参考图直接转换成单一模型。
需要外部建模时以GLB导入，先验证一个模型的轮廓、材质、体积和加载耗时。Hyper3D连接、价格、授权未验证，不能列为已具备能力或默认付费执行。Blender可作为可选资产整理工具，不要求用户学习或等待整岛离线渲染。简单资产可在现有工具内制作，但不能再以球体堆叠替代关键资产质量。

## 用户体验策划

首次访问：场景稳定出现后展示一句“点水獭看作品，也可以直接选下方分类”。音乐默认关闭，访客操作后开启。避免强制教程。
悬停或键盘聚焦：显示完整分类标签、轻微描边，扩大透明点击范围；避免用大幅弹跳提示。
选中水獭：停止游泳，进入可见的展示位置或温和转向访客；模型不变云。随后右侧显示分类内容，选中状态同步底部导航。关闭后恢复游泳。移动端不依赖悬停。
遮挡处理：动物被岛遮挡时隐藏其悬浮标签，底部分类始终可用；选中时先保证目标可见，再做轻微镜头调整，减弱动态时直接切换静态状态。
作品面板：分类简介、精选作品封面、名称、本人角色、简短贡献、详情链接。使用真实授权素材；缺图时采用清晰文字卡，不伪造作品图。桌面宽度约360–440 CSS像素，标题控制行长；手机底部抽屉。打开时为场景与公共控件留出位置。
分类扩展：数量不绑定建筑。4/6/8类验证动物间距；更多分类使用分组/分页导航与按需展示动物，避免无限生成造成拥挤。
装饰互动：保留现有三项动态与点击水纹。昼夜、天气、任务管理不纳入本轮核心改版，避免稀释作品展示。

## 执行顺序与交付门槛

P0 先修显示问题：坡道痕迹、标签遮挡、面板标题孤行和控件覆盖。验证默认及旋转角度。
P1 质量样板：精修一栋花房和一只水獭，放到实际Three.js环境验收近景。达不到目标不批量铺满场景。
P2 整岛空间：高低台、连接道路、码头海湾、秋千区；统一比例、岸线、海水、柔光和稀疏植物。
P3 作品浏览：真实封面与角色信息、稳定分类入口、选中反馈、桌面面板及手机抽屉。
P4 回归验证：4/6/8分类、四场景往返、浏览进度、键盘、减弱动态、手机与桌面；记录目标设备帧率和加载体积后再确定性能预算，不以构建通过代表画面通过。

验收：默认视角一眼读出主次建筑、前后高差和海湾；近景无穿插/贴片裂痕；标签不指向被遮挡动物；任何分类可通过固定导航进入；作品面板首屏有实际作品信息，关闭与返回清楚；船和秋千运动轴正确；原三场景行为不回退。
