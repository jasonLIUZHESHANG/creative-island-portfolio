日期：2026-11-17。依据 `plan.md` 的 P0–P4 执行；未改造另外三个场景的美术。

## 已实施

- P0：道路改为贴合地形的网格，关闭道路自身阴影并使用多边形偏移，消除坡道黑色碎痕；遮挡水獭时隐藏悬浮标签；右侧面板标题行长和公共控件位置已调整。

- P2：后方花房与薄荷小屋、前方海湾码头和秋千形成空间分区；小径收窄并加圆头，岸边岩体改为分组，海面条纹减弱。

- P4：4/6/8 个分类的动物间距、超出 8 个的展示、减弱动态、船和秋千的运动轴由自动测试覆盖。Chrome 已验证四场景往返、进度、键盘关闭与焦点回退、移动端抽屉滚动。
