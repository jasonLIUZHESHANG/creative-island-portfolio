# 小小旷野作品集

模板在本技能的 `assets/template/`。复制到用户指定的新工作目录后修改，不直接改安装目录。若用户已有项目，先读取其 README 和 src/portfolio-config.js，在现有项目继续。

## 收集与制作

1. 先询问展示姓名、一句话介绍、已有作品链接或材料；已有答案直接沿用。允许先用明确标记的示例内容预览，不编造成果。
2. 根据材料建议分类，用户也可以指定。分类数量由内容决定；动物数量自动跟随 `portfolioSections`。建议 3–8 类便于浏览，更多分类可保留并验证标签密度和导航滚动。
3. **选择你的角色**：默认黑夹克、蓝色牛仔裤、小白鞋；或文字描述发型/服装；或用户自愿提供的授权照片。总结可见外观再实现，缺失细节说明假设。照片不复制进网站或发布包。建模入口 `src/original-models.js`，保留动画关节和脚底原点。
4. 编辑 `src/portfolio-config.js`：profile 为展示信息、外链、默认场景；portfolioSections 每项包含 short、title、intro、items（[作品名,说明] 数组）。同一组分类供四个场景共享。团队作品注明用户角色，不冒称个人作品。网站链接只使用用户确认的公开地址。
5. Node.js >=20.19，执行 `npm ci`，然后 `npm run dev -- --port 4174`。端口占用改用空闲端口，不停止无关进程。默认场景 0 草原、1 雪屋、2 海岛；URL `?scene=2` 可覆盖。
6. 用户只改内容时不重做场景。视觉要求：圆润稀疏、低对比、整屏环境统一。点击动物保持原形，右侧显示项目。海岛建筑为固定景物，不和分类数量绑定。
7. 运行 `npm test`、`npm run build`，实际浏览器检查分类入口、关闭、场景往返、全景复位、音乐、手机布局。区分实际验证与未验证，不把静态效果图当成可交互成品。
8. `dist/` 是静态网站；可部署到 GitHub Pages 等静态托管，base 已设置为相对路径。用户提供仓库并要求发布后再操作远程。保留 LICENSE 与原项目署名。

## 不变量

- 点击地面移动人物；拖动旋转，滚轮缩放；海面点击产生波纹，拖动不触发点击。
- 四个场景共享分类导航、浏览进度、帮助、音乐开关。
- 浏览进度仅保存在本机，音乐默认关闭；支持减弱动态偏好。
- 不依赖 Blender、付费 API 或服务器；需要支持 WebGL 的浏览器。

云朵花语（场景索引 3）：水獭绕岛游泳，选中后暂停；小船轻轻起伏，秋千前后摆动。尊重系统减弱动态偏好。
