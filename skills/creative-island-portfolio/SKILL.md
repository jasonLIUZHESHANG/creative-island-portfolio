# 创作岛互动作品集

本技能自带网站模板，位于 `assets/template/`。先把模板复制到用户指定的**新目录**，再编辑副本。不要改动已安装的技能文件；若用户已有作品集项目，先读其 README 和 `src/portfolio-config.js`，在原项目继续。

## 和新人一起完成

1. 先说明成品：一个能旋转和缩放的作品集网站，访客通过水獭等动物或底部分类打开作品。四个场景分别是云朵花语、海风小岛、风栖草原、雪线暖屋；默认展示云朵花语。询问用户要把新项目放在哪里。若用户不知道，建议在其文稿或项目目录新建 `my-portfolio`。
2. 分轮收集素材，不要求一次填完：展示姓名、一句话介绍、希望公开的链接；每件作品的名称、本人角色、具体贡献、图片和详情链接；希望使用的分类。用户没有图片或链接时保留文字卡，不编造。团队作品明确写团队和本人角色。未获授权的照片不要复制进网站。
3. 给出分类建议供用户确认。通常 3–8 类；分类数量决定动物数量，不决定建筑数量。用户也可只提供 1–2 件作品，先做明确标注的草稿，预览后继续补充。
4. 询问角色外观。默认黑夹克、蓝牛仔裤、白鞋；也可用文字描述发型和服装，或让用户自愿提供有权使用的照片参考。只把照片用作参考，不复制到网站或发布包。角色实现位于 `src/original-models.js`，保留动画关节与脚底原点。
5. 编辑副本的 `src/portfolio-config.js`：`profile` 是姓名、介绍、页脚、作品集总链接和默认场景；`portfolioSections` 是分类。每个 `items` 条目格式为 `[作品名, 本人角色与贡献, 可选封面路径, 可选详情链接]`。封面建议复制到副本的 `public/covers/`，路径写 `/covers/文件名`；没有封面时省略第三项。第四项只写用户确认可公开的链接。不要把示例作品当成用户成果。
6. 检查 Node.js 是否为 20.19 或更高版本。进入副本目录，运行 `npm ci` 和 `npm run dev -- --port 4174`；如端口被占用，换空闲端口并告诉用户新地址。给用户打开本地预览，说明如何点分类、关闭详情、旋转、缩放与切换场景。
7. 和用户逐项核对：姓名与简介、每件作品的角色和贡献、图片授权、链接、四个场景、手机布局。先根据反馈修改，再运行 `npm test` 和 `npm run build`。有失败要修复并重试；不能以构建通过代替实际浏览器检查。
8. 最后说明副本路径、预览地址、已填和待补的内容。`dist/` 是可部署的静态网站。只有用户明确要求发布时才处理 GitHub Pages 等远程服务；发布前再次核对公开内容。

## 约束

- 四个场景共享分类、底部导航、浏览进度、帮助和音乐开关；进度仅保存在访客浏览器，音乐默认关闭。
- 点击地面移动人物；拖动旋转，滚轮缩放；海面点击产生水纹，拖动不触发点击。减弱动态偏好应生效。
- 不依赖 Blender、付费 API 或后端；运行需要支持 WebGL 的浏览器。
- 尊重原项目 LICENSE；个人姓名、照片和作品不因代码许可而自动授权复用。
