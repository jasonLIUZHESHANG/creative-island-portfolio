# 我的创作岛 · 互动作品集

这是可改成你个人作品集的四场景网站模板。默认打开“云朵花语”；访客可以点水獭或底部分类看作品，也可以切换海风小岛、风栖草原和雪线暖屋。这里的作品名称都是**示例占位内容**，发布前请换成真实作品。

## 第一次制作

如果你通过 WorkBuddy 安装了 `creative-island-portfolio` 技能，直接在新任务里说：

> 使用 creative-island-portfolio 技能，帮我把模板复制到一个新项目，做成我的互动作品集。请一步一步问我展示姓名、作品、本人角色、贡献和图片；先在本地预览，不要发布。

WorkBuddy 会引导你收集内容、制作和检查。你可以先只提供 1–2 件作品，其他内容以后再补。没有图片时使用文字卡；团队作品要写清本人负责的部分。

## 自己运行

需要 Node.js 20.19 或更新版本。在这个目录打开终端：

```sh
npm ci
npm run dev -- --port 4174
```

然后打开 <http://127.0.0.1:4174/>。如果 4174 端口被占用，请查看终端输出的新地址。

## 内容放在哪里

编辑 `src/portfolio-config.js`：

- `profile.name` 是页面上显示的姓名或作品集名；`subtitle` 和 `byline` 是介绍；`url` 是你的完整作品集链接，没有就留空；`defaultScene: 3` 表示默认打开云朵花语。
- `portfolioSections` 是作品分类。每条作品按 `[作品名, 本人角色与贡献, 可选封面路径, 可选详情链接]` 填写。
- 封面放在 `public/covers/`，例如 `public/covers/project.jpg`，配置中写 `/covers/project.jpg`。没有图片或详情链接时可省略对应字段，页面会显示文字卡。

作品与图片应当是你有权公开展示的内容。不要把个人私密资料或未授权照片放进网站。

## 检查与打包

```sh
npm test
npm run build
npm run preview -- --port 4175
```

打开预览后，检查四个场景、作品分类、详情面板、手机布局、图片和链接。`dist/` 是打包后的网站文件；只有你决定公开时再部署。网站需要支持 WebGL 的浏览器。代码许可见 `LICENSE`，个人作品与照片不因此获得转用授权。
